# AIマスター標準（4段階版）
## 全体像（1枚サマリ）

| 段階 | 問われる力 | ACMM遷移 | 人間の役割 |
|---|---|---|---|
| 初級 | 委任・検証 | L1に留まる | Executor |
| 中級 | 調査・コンテキスト設計 | L1→L2 | Rule-writer |
| 上級 | 基盤整備・並列・計測 | L2→L3→L4 | Analyst→Governor |
| 管理級 | ガバナンス・組織設計 | L4→L5 | Strategist |

**認定ロジック**: 段階は個人の操作スキルだが、遷移トリガーはACMMの組織的成熟度と対応させることで、「上手に使える人」と「組織を成熟させられる人」を区別できる設計です。
---

## 初級（Foundation）— 対話・単一タスク委任
*旧Lv1-2相当*

- [ ] エージェントにタスクを自然言語で指示できる
- [ ] Plan Modeで実装方針を事前確認・承認できる
- [ ] 生成差分（diff）を読んで妥当性判断できる
- [ ] 誤動作時に中断・ロールバックできる
- [ ] バグ修正・小機能追加を1タスクとして委任し、テスト実行〜確認まで一連でやらせられる
- [ ] 権限設定（allow/deny/ask）を理解し使い分けられる
- [ ] PR差分をレビューさせ、指摘の妥当性を判断できる

**対応ACMM**: L1 Assisted 相当。まだ個人の頭の中に知識がある段階。

---

## 中級（Practitioner）— 調査・保守・コンテキスト設計
*旧Lv3-4相当*

- [ ] 大規模コードベース調査、バグ再現〜修正案提示を一貫委任できる
- [ ] 設計書レビュー（整合性・非機能要件観点）を委任し、優先順位づけできる
- [ ] コンテキストウィンドウを意識し、必要な情報のみを渡せる
- [ ] compactのタイミング判断、セッション跨ぎの引き継ぎドキュメント作成ができる
- [ ] Subagentの独立コンテキストの仕組みを理解し、調査タスクを委任して要約だけ受け取れる
- [ ] **「なぜ検出できなかったか」を問い、単発修正でなく仕組み改善（新テスト・新ルール）を引き出せる**

**対応ACMM**: L1→L2への遷移を自力で起こせる段階。CLAUDE.mdのような指示ファイルの効果を体感し、一貫性の価値を理解している。

---

## 上級（Expert）— 基盤整備・並列・自動化
*旧Lv5-7相当*

- [ ] CLAUDE.md/AGENTS.mdを作成・最適化し、カスタムSubagent（description/tools/model設定）を設計できる
- [ ] Skillsとして繰り返し業務を切り出し、Hooksで強制ルールを組み込める
- [ ] タスクを独立サブタスクに分解し、fan-outで複数エージェントに並列実行を指示できる（worktree分離含む）
- [ ] 定期実行（スケジュール/API/GitHubイベントトリガー）で自動化タスクを設計・監視できる
- [ ] **フレーキーテストを許容せず、自律ワークフローのゲートとして機能する決定論的テストを設計できる**
- [ ] PR受理率・カバレッジ等の定量指標を設計し、AI活用の実効性を測定できる
- [ ] 並列度とコストのトレードオフを判断し、自動化の暴走（止め忘れ）を防げる

**対応ACMM**: L2→L3→L4への遷移を主導できる段階。測定可能な指標を整備し（Analyst）、さらに閾値に応じた自動反応の仕組みを作れる（Governor）。

---

## 管理級（Steward）— 組織運用・ガバナンス
*旧Lv8相当*

- [ ] 組織全体のCLAUDE.md/Skills/Hooks/ガイドラインを統括し、標準化できる
- [ ] 複数エージェントの役割分担・情報引き継ぎを設計し、失敗時の影響を局所化できる
- [ ] **技術的負債がAI出力品質を直接劣化させることを理解し、リファクタを投資として優先できる**
- [ ] **コードベース自体がAIの操作マニュアルとなる設計（テスト=信頼境界、指示=判断基準、指標=優先順位）ができる**
- [ ] 自組織のACMMレベルを客観的に診断し、レベルスキップせず次の遷移に必要な機構から着手できる
- [ ] 活用のROI・生産性を計測し、他メンバーのオンボーディングを実施できる
- [ ] コミュニティ/組織主導のIssue→実装パイプラインなど、人間不在でも回る運用を設計できる

**対応ACMM**: L4→L5への遷移を主導。人間の役割はコードを書くことから、ガバナンス・アーキテクチャ・価値判断へ移行する（Strategist）。
