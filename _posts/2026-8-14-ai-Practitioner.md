**AGENT中級理解**

**アーキテクチャ/実行モデル**
- [ ] Subagentの役割分担・並列実行の仕組みを理解している
- [ ] Skillsの定義方法・呼び出しトリガーを理解している
- [ ] Hooksでライフサイクルイベント（pre/post-tool等）に介入できると理解している
- [ ] MCP(Model Context Protocol)によるツール/データソース接続の仕組みを理解している
- [ ] エージェントループの内部構造（観測→思考→行動→検証）を説明できる

**コンテキスト管理**
- [ ] compact発生タイミングと情報欠落リスクを理解している
- [ ] AGENT.md/CLAUDE.md等の設定ファイルの階層・優先順位を理解している
- [ ] 長時間セッションでのコンテキスト設計（要約・引き継ぎファイル運用）ができる
- [ ] トークン予算を意識したプロンプト/ツール結果の圧縮設計ができる

**権限・実行制御**
- [ ] allow/deny/askの権限設定をプロジェクト単位でカスタマイズできる
- [ ] 破壊的操作（rm, force push等）への防御設計ができる
- [ ] サンドボックス/コンテナ実行環境の必要性を理解している

**ツール/MCP運用**
- [ ] 複数MCPサーバーの併用時の競合・優先順位を理解している
- [ ] カスタムツール（bash script, API連携）を自作・登録できる
- [ ] ツール呼び出し失敗時のリトライ/フォールバック設計を理解している

**マルチエージェント設計**
- [ ] タスク分割によるSubagent間の役割設計ができる
- [ ] Subagent間の情報受け渡し（成果物・要約）の設計ができる
- [ ] オーケストレーター/ワーカーパターンを理解している

**品質・検証**
- [ ] 生成物の自動テスト・lint連携によるセルフ検証ループを構築できる
- [ ] Plan Modeでの計画レビューを実運用に組み込める
- [ ] 出力の非決定性を考慮したCI/再現性設計を理解している

**リスク・運用**
- [ ] 機密情報・シークレットのツール経由漏洩リスクを理解している
- [ ] コスト管理（トークン/API呼び出し回数）の監視設計ができる
- [ ] 本番運用時のロールバック/監査ログ設計を理解している
