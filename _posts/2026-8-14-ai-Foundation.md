**AGENT基礎理解**

**LLM基本**
- [ ] LLMが確率的トークン予測であり、ハルシネーションを構造的に含みうると理解している
- [ ] 学習データのカットオフ日が存在し、最新情報は知らない/誤る可能性があると理解している
- [ ] トークン・コンテキストウィンドウの概念（入出力上限、コスト課金単位）を知っている
- [ ] プロンプトの書き方（明確な指示・具体例・制約提示）が出力品質を左右すると理解している
- [ ] モデルにも得意/不得意領域があり万能ではないと理解している（例: 厳密な数値計算、最新事実、長い一貫性維持）
- [ ] 同じ指示でも毎回微妙に異なる出力になりうる（非決定性）と理解している
- [ ] モデルには複数のグレード（速度/コスト/精度のトレードオフ）があり、タスクに応じて選択可能と知っている

**エージェント基本**
- [ ] チャット（対話のみ）とエージェント（ツール実行・自律ループ）の違いを理解している
- [ ] エージェントがファイル読み書き・bashコマンド実行等のツールを使えることを知っている
- [ ] エージェントが計画→実行→検証を自律的に反復することを知っている
- [ ] Plan Mode（実装前に方針確認できるモード）の存在と使い所を知っている
- [ ] 権限モデル（allow/deny/ask）の存在と、暴走防止の仕組みだと理解している
- [ ] セッション/コンテキストが切れると過去の記憶が失われうると理解している（要約・引き継ぎの必要性）
- [ ] compact（コンテキスト圧縮）という概念があると知っている
- [ ] AGENT.mdという指示ファイルがエージェントの挙動に影響することを知っている（作成せずとも存在は理解）
- [ ] Subagent/Skills/Hooks/MCPという概念があることを名前だけでも知っている（詳細運用は中級以降）
- [ ] ツール呼び出し（web検索・コード実行等）の結果に基づいて回答するモードがあると知っている

**リスク認識**
- [ ] 生成コードの著作権/ライセンス上の注意点があると知っている
- [ ] 自動実行コマンドが意図せず破壊的操作（削除・上書き等）を行うリスクを理解している
- [ ] 生成物（コード・文章）を検証なしに本番/公開に使うリスクを理解している
