**AGENT管理級（Steward）理解**

**戦略・投資判断**
- [ ] 組織全体のAI/エージェント活用ロードマップを策定できる
- [ ] ビルド/バイ/パートナーの意思決定基準を持っている
- [ ] ROI・生産性指標を定義し経営層に報告できる
- [ ] モデル/ベンダーロックインリスクを評価し多様化戦略を立てられる

**ガバナンス・ポリシー**
- [ ] 全社的なAI利用ポリシー（許可範囲・禁止事項）を策定・維持できる
- [ ] 承認フロー・変更管理プロセスをエージェント運用に組み込める
- [ ] 責任分界（人間の最終承認ポイント）を組織設計に反映できる
- [ ] インシデント発生時のエスカレーション体制を整備している

**リスク管理**
- [ ] 法務/コンプライアンス（著作権・データ保護・輸出規制等）を横断的に評価できる
- [ ] サードパーティ監査・認証取得の要否を判断できる
- [ ] レピュテーションリスク（誤情報・バイアス・事故）への対応方針を持っている
- [ ] サプライチェーン全体（モデル/MCP/データソース）のリスクを継続的に評価できる

**組織・人材**
- [ ] チームのAIリテラシー育成計画（研修・認定制度）を設計できる
- [ ] 役割別（開発者/非開発者）のツール導入・権限方針を策定できる
- [ ] 内部エキスパート/推進者(champion)ネットワークを構築できる
- [ ] 採用・評価基準にAI活用能力を組み込める

**技術基盤の統治**
- [ ] 全社共通の標準（AGENT.md規約、Skillsライブラリ、MCP接続基盤）を整備できる
- [ ] セキュリティ/監査基盤を全社エージェント運用に一元適用できる
- [ ] コスト配分・チャージバックの仕組みを設計できる
- [ ] 技術的負債（乱立したエージェント資産）の棚卸し・統廃合ができる

**継続的改善**
- [ ] 全社的な効果測定・フィードバックループを運用している
- [ ] 新技術（新モデル・新プロトコル）の評価・展開プロセスを統括している
- [ ] 外部コミュニティ・業界動向のウォッチ体制を持っている
