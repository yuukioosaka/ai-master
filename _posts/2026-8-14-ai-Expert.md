**AGENT上級理解**

**アーキテクチャ設計**
- [ ] 複数エージェント・複数MCPサーバーからなる分散システム全体のアーキテクチャを設計できる
- [ ] エージェントループの独自実装（観測/計画/実行/検証の再構築）ができる
- [ ] 長期記憶（ベクトルDB・外部ストア等）の設計・統合ができる
- [ ] イベント駆動/非同期でのマルチエージェント協調パターンを設計できる
- [ ] オーケストレーター障害時のフェイルオーバー設計ができる

**コンテキスト/メモリ最適化**
- [ ] タスク特性に応じた動的コンテキスト圧縮戦略を設計できる
- [ ] 複数セッション/複数エージェント間でのメモリ共有・同期の一貫性を担保できる
- [ ] コンテキスト汚染（誤情報の伝播）を検知・防止する仕組みを設計できる

**権限・セキュリティ**
- [ ] 最小権限原則に基づく動的権限付与（タスクごとのスコープ制御）を設計できる
- [ ] プロンプトインジェクション/ツール経由の攻撃ベクトルを分析し防御策を実装できる
- [ ] マルチテナント環境での分離・監査設計ができる
- [ ] サプライチェーンリスク（MCPサーバー・外部ツールの信頼性検証）を評価できる

**評価・品質保証**
- [ ] エージェント性能の定量評価基盤（ベンチマーク・回帰テスト）を構築できる
- [ ] 非決定性を前提としたA/Bテスト・統計的評価設計ができる
- [ ] 自己改善ループ（生成物→評価→修正指示の自動化）を構築できる
- [ ] Human-in-the-loopの適切な介入ポイントを設計できる

**運用・スケーリング**
- [ ] 大規模並列エージェント実行時のリソース/コスト最適化ができる
- [ ] レイテンシ・スループットのボトルネック分析とチューニングができる
- [ ] 本番インシデント対応（暴走・無限ループ検知と自動停止）の仕組みを構築できる
- [ ] 監査ログ・トレーシング基盤（実行履歴の完全な再現性）を整備できる

**組織・ガバナンス**
- [ ] チーム全体でのAGENT.md/Skills/Hooksの標準化・レビュー体制を構築できる
- [ ] エージェント運用のガバナンスポリシー（承認フロー・変更管理）を策定できる
- [ ] 新モデル/新ツールの評価・移行プロセスを設計できる
